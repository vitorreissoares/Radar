        Como o índice é calculado

        Cada comentário vale 1 (positivo), 0,5 (neutro) ou 0 (negativo), e o índice é a média desses valores sobre todos os comentários do grupo (cada comentário pesa igual). No índice geral, cada postagem entra uma vez só, mesmo quando pertence a mais de uma categoria; por isso ele não é a média dos índices das categorias, que contaria os mesmos comentários mais de uma vez.

        O intervalo de confiança de 95% considera que os comentários de uma mesma postagem não são independentes (erro-padrão robusto por postagem, para o estimador de razão) e usa a distribuição t com (número de postagens − 1) graus de liberdade, o que o deixa mais largo quando há poucas postagens. Intervalos que se sobrepõem indicam que a diferença entre os grupos pode ser casual.
